Tokens and NFT-style documents

DashMint Lab

A collectible-card marketplace app where NFT-style documents can be minted, transferred, listed, purchased, and burned.

  • Marketplace flows are document ownership changes.
  • Prices turn owned documents into listings that other identities can purchase.
  • A fixed-supply token controls minting capacity and can be transferred between identities.

The core pattern is NFT-style document ownership plus token scarcity: cards move through marketplace actions, while tokens control who can create new supply.

Identity-owned documents

Dashnote

A notes app where entries belong to a Dash Platform identity, not a device, account database, or browser session.

  • Notes are mutable Platform documents with owner-scoped indexes for fast retrieval.
  • Any compatible client can read the same contract and render the same user-owned data.
  • Revision numbers and Platform timestamps make edits explicit instead of hidden in app state.

The special part is portability: identity-owned notes can move across apps while Platform handles document ownership, ordering, revision checks, and timestamp metadata.

Ratings and aggregate queries

DashRate

A tutorial-resource ratings app centered on Platform v4 relational document queries and grouped counts.

  • Read-only users can browse resources, aggregates, and recent reviews.
  • Signed-in users can create one review per resource and edit it later.
  • Count, grouped count, rating filters, and document history are visible in one UI.

Proof of existence

DashProof Lab

A file proof tutorial that keeps file contents local, hashes them in the browser, and anchors only the digest plus metadata on Platform.

  • SHA-256 is computed locally before any Platform call.
  • Users can verify a file by hash and review proof history by owner or chain ID.
  • Starter files make the demo reproducible without uploading private files.
